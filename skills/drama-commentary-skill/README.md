# drama-commentary-skill

Public packaging for the reusable `drama-commentary-skill`.

This skill turns a lawful source video into a reviewable commentary draft package:

- commentary script
- Chinese narration draft
- candidate asset flow
- draft video handoff

## What it is for

- movie commentary
- short-drama recap
- plot-summary videos
- first-pass commentary drafts from a source video

## Core workflow

`source video -> video understanding -> commentary script -> narration draft -> candidate assets -> user selection -> draft video`

## Included files

- `SKILL.md`
- `references/workflow.md`
- `references/style-profiles.md`
- `references/pronunciation-draft.md`
- `references/asset-integration.md`
- `references/video-handoff.md`

## Notes

- Built for lawful source material only
- External assets are candidate-only until approved
- Designed to be a durable reusable skill, not a one-off script
